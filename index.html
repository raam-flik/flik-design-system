Colours

Five brand colours. Violet is the only colour for things people click; navy carries the text; cyan, magenta and orange live in the brand ribbon.

Use only these colours. Every colour on a FLIK page or in the dashboard comes from this list. No other colours, no new tints or shades, and no gradients except the brand ribbon. Bank, e-wallet, card and courier logos keep their own colours. Need a new colour? Ask for it to be added here first.

Components

Every piece below is live, built from the real styles. Each one says when to use it and what to avoid.

Reuse first. Always build with these components. Combine and configure what is here before making anything new. If nothing fits, the new piece is added to this design system (with an example and rules) and approved before it is used. No one-off buttons, cards, tables or badges.

Website components

Used on flik.co.id: buttons, links, headings, cards.

Button

The marketing call-to-action: 40px tall, 4px corners, 15px medium label.

Use one fl-btn--primary per view for the main action (Contact sales, Apply now, Start shipping free) and fl-btn--secondary beside it for the second choice. On the dark band use fl-btn--on-dark for the second button.

Don't put two primary buttons side by side, use orange or gradients on buttons, or shorten the 40px height (stack full width on phones instead: 46px tall).

Section Heading

The opening of a marketing section: optional label, a two-sentence heading, optional lead.

How it works

Simple terms, priced fairly. Know exactly what you will pay before you sign.

Compare rates from every courier, ship one by one or in bulk, and track every package.

Use at the top of every section. The heading's first sentence is the claim in ink; the second explains it in muted (<span class="soft">). Keep both short so the heading fits two lines at 1180px.

Don't add a separate subtitle paragraph under the heading when the soft sentence already explains it, or use numbered eyebrows (01 / 02) unless the sections really are steps.

Dashboard components

The building blocks of every dashboard page.

App Button

The dashboard button: 32px tall, 6px corners, 13.5px medium label.

Use fl-abtn--primary for the one main action in a view or dialog, fl-abtn--outline for everything else (Export, Previous, Cancel) and fl-abtn--danger for destructive actions (Refund, Delete). Round 38px fl-iconbtn buttons sit in the top bar; the violet fl-iconbtn--create opens the Create menu.

Don't use the 40px marketing Button inside the dashboard, or a red filled button (danger is red text on white).

Sidebar Nav

The 240px dashboard sidebar with the business switcher on top, the main pages, then a Products group.

Products

Use the same order everywhere: Home, Transactions, Customers, then Products (Checkout, Shipping, Funding). The current page is primary with a medium weight. Below 960px it becomes a drawer opened from the top bar.

Don't add a search box or breadcrumbs to the sidebar.

Status Badge

A bordered status label for table rows and detail headers (22px, 5px corners).

Succeeded UncapturedFailedRefundedCanceled

Use one per row in the Status column: ok Succeeded / Paid / Delivered, warn Pending / Uncaptured, bad Failed / Disputed, info Refunded, neutral Canceled / Incomplete. Always write the word; colour never carries the meaning alone.

Don't use marketing Pill styles in the dashboard.

Tabs

Underline tabs that split one list into views, with an optional count in app-faint.

Use under the page title of list and detail pages. The active tab is primary with a 2px underline; the row scrolls sideways on phones.

Don't use tabs to switch between unrelated pages (use the sidebar).

Toast

A short dark confirmation at the bottom centre, gone after about 2.6 seconds.

Refund of Rp349.000 sent

Use after an action finishes: "Exported 248 transactions", "Refund sent". State what happened in past tense.

Don't use toasts for errors the user must act on.

Writing

How FLIK sounds, on the website and in the dashboard.

  • Plain, short, specific. Write the way a helpful account manager talks. Lead with the outcome and the number: "Checkout in 30 seconds.", "Every courier, one dashboard. Up to 40% less.", "One fixed margin, no hidden fees."
  • You and your. Speak to the merchant ("your balance", "your shoppers"). FLIK refers to itself as FLIK or "the FLIK team", never "we" in headings.
  • Sentence case everywhere: headings, buttons, menu items ("Contact sales", "Start shipping free"). Product names keep their capitals (Checkout, Merchant Cash Advance, FLIK Account).
  • Languages. English first, everywhere: the website (English at /, Bahasa Indonesia second at /id/ with the same slugs) and the dashboard, including every menu name (Checkout personalization, Reports, Shipping settings).
  • Formats. Money Rp1.250.000 (no space, no decimals, dot thousands); short money Rp250 jt, Rp5 M; amounts in tables are left-aligned with no currency column; dates 14 Oct 2026, with time 14 Oct 2026, 10:42; phone +62 812-3456-7890; AWB numbers in the mono face.
  • Only real claims. Use the figures in the product reference (30-second checkout, 3× faster, 40% off shipping, 3% COD fee, 99% shipment creation success). Mark example data in mockups as example data.
  • Buttons say what happens ("Refund", "Create shipments"); toasts confirm in past tense ("Refund sent").
  • No emoji, no exclamation marks in UI, no "revolutionary", "seamless" or other filler.
