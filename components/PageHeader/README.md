# PageHeader

The title row of a dashboard list page: the 28px page title on the left and the page's one primary action on the right.

**Use** on every list page that can create something (Invoices → Create invoice, Shipments → Create shipment). The action opens the create flow. Tabs, filters and the table follow below it.

**Don't** add a description under the title, or a second primary button; secondary actions (Export) belong in the filter row.
