# RadioList

Stacked radio options with a bold name and a description, divided by `app-line` hairlines; the selected option can reveal its own settings (`ChoicePills`) underneath.

**Use** for 2–4 mutually exclusive modes inside a form, such as an invoice's Payment collection (Request payment, Request a down payment, Cash on delivery).

**Don't** reveal settings for unselected options, or use it for more than four choices (use a select).
