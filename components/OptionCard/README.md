# OptionCard

A large selectable card for choosing between two or three ways of doing something; the selected card gets a 2px `primary` ring and its icon tile turns `primary-soft`.

**Use** for decisions that change the rest of the form: Manual entry or Bulk upload, COD or Non-COD. Two cards per row (one on phones), each with an icon, a bold name and one short line.

**Don't** use for long lists or yes/no settings (use `RadioList` or `Checkbox`).
