# Checkbox

16px checkboxes (with a mixed state) and radios for filter popovers and table selection.

**Use** checkboxes for multi-select filters and row selection; the header checkbox shows `mixed` when some rows are selected. Radios for single-choice filters such as date ranges.

**Markup.** `.fl-cb(.on|.mixed)` and `.fl-rdo(.on)` next to a label inside `.fl-check`; use real `<input>` elements for keyboard access and style them with these classes.
