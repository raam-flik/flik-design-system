# ChoicePills

Pill-shaped single-choice buttons for short values; the chosen pill gets a 1.5px `primary` ring and `primary` text.

**Use** for due dates (Due in 7 / 14 / 30 days), down-payment shares (30% / 50% now) and pickup days and time slots. Keep labels to a few words; group days and times as two separate rows.

**Don't** use them as filters on a list (use `FilterChip`) or for actions (use `AppButton`).
