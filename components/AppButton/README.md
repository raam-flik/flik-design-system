# AppButton

The dashboard button: 32px tall, 6px corners, 13.5px medium label.

**Use** `fl-abtn--primary` for the one main action in a view or dialog, `fl-abtn--outline` for everything else (Export, Previous, Cancel) and `fl-abtn--danger` for destructive actions (Refund, Delete). Round 38px `fl-iconbtn` buttons sit in the top bar; the violet `fl-iconbtn--create` opens the Create menu.

**Don't** use the 40px marketing `Button` inside the dashboard, or a red filled button (danger is red text on white).
