# SummaryPanel

The running total beside a stepped flow: a 320px `app-hover` panel with label–value rows and a ruled total at the bottom; it stays in view (sticky) while the form scrolls.

**Use** in Create shipment (shipments, payment type, COD value, courier, pickup, fees, You pay). Values not chosen yet show "—". Below 1100px it moves under the form.

**Don't** put actions in it; Continue lives in the `FlowShell` footer.
