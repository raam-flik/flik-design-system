# Stepper

Numbered steps for a multi-step flow, centred in the `FlowShell` top bar: done steps show a `primary` tick, the current step a filled `primary` circle, later steps stay `app-faint`.

**Use** for flows of 3–6 steps with short one-word names (Details, Courier, Pickup, Summary, Payment). Below 1100px hide the labels and keep the numbers.

**Don't** make steps clickable to jump ahead; going back is the footer's Back button or an Edit link on the summary step.
