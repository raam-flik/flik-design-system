# Pill

A small rounded status label (20px, 11.5px text) used inside marketing mockups and cards.

**Use** to tag a state in a product mockup: Funded, Approved, Connected, Auto, Best price. Pick the tone by meaning: `ok` success, `info` neutral-positive or "Auto", `warn` waiting, `bad` failed, `neutral` not started.

**Markup.** `<span class="fl-pill fl-pill--ok">Funded</span>`.

**Don't** use pills as buttons, or in dashboard tables (use `StatusBadge` there).
