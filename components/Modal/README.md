# Modal

A centred 440px dialog for short tasks: a title, a few fields, Cancel and one primary action.

**Use** for confirmations and short forms (Refund, Top up balance). Longer work goes in the detail drawer. The scrim is `app-ink` at 35%.

**Don't** add text under the title; the footer has Cancel and the primary button only, and the primary stays disabled until the form is valid.
