# SidebarNav

The 240px dashboard sidebar with the business switcher on top, the main pages, then a Products group.

**Use** the same order everywhere: Home, Transactions, Customers, then Products (Checkout, Shipping, Funding). The current page is `primary` with a medium weight. Below 960px it becomes a drawer opened from the top bar.

**Don't** add a search box or breadcrumbs to the sidebar.
