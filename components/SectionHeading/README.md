# SectionHeading

The opening of a marketing section: optional label, a two-sentence heading, optional lead.

**Use** at the top of every section. The heading's first sentence is the claim in `ink`; the second explains it in `muted` (`<span class="soft">`). Keep both short so the heading fits two lines at 1180px.

**Markup.** `<span class="fl-label"><i></i>Label</span>`, `<h2 class="fl-heading">Claim. <span class="soft">Explanation.</span></h2>`, `<p class="fl-lead">…</p>`.

**Don't** add a separate subtitle paragraph under the heading when the soft sentence already explains it, or use numbered eyebrows (01 / 02) unless the sections really are steps.
