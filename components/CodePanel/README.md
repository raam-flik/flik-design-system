# CodePanel

A monospace code block on the `dark` band, for the Developers section and API cards.

**Use** only on `dark` or `dark-raised` surfaces; text in `code-text`, secondary copy in `on-dark-muted`.

**Markup.** `<div class="fl-code">…</div>`; keep examples short (under 8 lines) and real.

**Don't** show API calls that do not exist in the docs.
