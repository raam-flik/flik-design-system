# EntityCard

The picked customer (or warehouse) inside a form: an initials avatar in `primary-soft`, the name, one line of contact details and a × to remove or a Change button.

**Use** right after a `Combobox` pick, and for the pickup warehouse in Create shipment (with an icon tile and a Change button that opens a radio list in a `Modal`).

**Don't** make the whole card a link; only the × or Change acts.
