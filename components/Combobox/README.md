# Combobox

A search field that opens a list of matches with an "Add new …" row at the top, for picking a customer or an item without leaving the form.

**Use** in create flows: Find or add a customer, Find or add an item (with prices on the right, from the product catalog). Typing filters the list; Escape or a click outside closes it. Once picked, a customer shows as an `EntityCard` (avatar, name, WhatsApp, email, ×).

**Don't** put more than 6–8 rows in view; let the search narrow it.
