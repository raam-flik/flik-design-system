# LineItems

Invoice lines: item name with its unit price, a `fl-qty` quantity stepper, the line total and a remove ×, closed by a bold Total row.

**Use** under the item `Combobox` in Create invoice. Quantity never goes below 1 (remove the line instead). On phones the line total hides; the Total row stays.

**Don't** let people type prices into the line; a custom item gets its price when added.
