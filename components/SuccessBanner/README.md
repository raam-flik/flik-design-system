# SuccessBanner

The end of a create flow: a navy banner with a green tick, what was created, its ID and the one follow-up action, then cards for what happens next.

**Use** after Confirm and pay in Create shipment (Print labels; Pickup and Pack your parcel cards), followed by View shipments and Create another. For lighter results (an invoice sent) a toast and a return to the list is enough.

**Don't** add confetti, emoji or exclamation marks.
