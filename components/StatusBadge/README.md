# StatusBadge

A bordered status label for table rows and detail headers (22px, 5px corners).

**Use** one per row in the Status column: `ok` Succeeded / Paid / Delivered, `warn` Pending / Uncaptured, `bad` Failed / Disputed, `info` Refunded, `neutral` Canceled / Incomplete. Always write the word; colour never carries the meaning alone.

**Don't** use marketing `Pill` styles in the dashboard.
