# TextLink

A violet 15px medium link with the hover arrow, for "learn more" style actions inside text and cards.

**Use** for secondary navigation: Explore Checkout, See pricing, Learn more. It sits at the end of a card or a paragraph.

**Markup.** `<a class="fl-link">Label <span class="fl-arrow">…</span></a>`.

**Don't** underline it, or use it for the main action of a section (use `Button`).
